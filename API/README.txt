R4OS API Contract
=================

ApiContract.json is the canonical language-neutral definition of R4XStart2,
R4LQuery2, the six platform groups, public payload types, signatures, status
and error domains, constants, limits, and operation semantics.

Generation2.json owns the independent current DriverApi2, ProtocolApi2,
AudioBackend2, AudioBackendStatus2 and AudioCaptureBackend2 records and their
callback signatures and selection. It contains no second platform slot list.
Generation2.baseline.json protects their exact accepted technical shape.
LegacyProjection.json temporarily retains only four inert historical holes
and reverse revision/header metadata until the planned provider/SDK cutover.
Old views derive from the current533 slots; current2 never derives from them.

ApiContract.baseline.json is the accepted compatibility baseline. It is not a
second source of truth and changes only with an intentionally accepted
contract change.

ApiContractGen
--------------

The repository-local generator deterministically produces:

- Zig ABI and export packages for the SDK;
- Zig ABI and provider packages for the kernel;
- the C ABI header;
- Zig and C conformance fixtures;
- group identities and table references;
- payload, operation, and parity documentation;
- the machine-readable API inventory.

All output is under Generated. zig build check compares every generated byte.
zig build test also runs negative generator tests and compiles the generated
Zig and C contracts.

Ownership boundary
------------------

The central schema owns only R4SYS, R4DESK, R4DRAW, R4NET, R4AUDIO, and
R4DEV. Named Runtime-R4L tables live with the owning library's baseline,
bindings, and tests. Only the generic mechanism under ABI is shared.

Existing tables and fixed-layout payloads remain binary stable. Extensions
are append-only; consumers check field sizes and function pointers rather
than relying on broad version assumptions.
